# RIA Demo Guide: Simplified Navigation

## One-minute pitch

RIA turns a meeting transcript, BRD and policy into evidence-linked requirements. It flags conflicts,
gaps and vague wording, keeps a person in control of review, creates user stories and important tests,
and exports a traceable BRD, Excel workbook and Jira CSV.

## Navigation
- **Home:** sessions, Open, Delete, New session, demo session.
- **Prepare & Run:** upload, check types, one-click analysis.
- **Review & Analysis:** requirements, conflicts and questions on one screen; clarification email and CSV.
- **Stories & Tests:** story board, Gherkin, tests, regenerate, Jira push.
- **Export:** traceability and Word / Excel / Jira CSV downloads.

## Five-minute demo
1. **Home (30 s):** **🧪 Load demo session**.
2. **Prepare & Run (45 s):** four documents detected with their types → **⚡ Run Complete AI Analysis** → metrics.
3. **Review & Analysis (2 min):** 🔴 5 conflicts → REQ-001 deep-dive: 45 / 60 / 90 days side by side → type
   "Finance confirmed 45 days" → **✔️ Resolve** → filter *Status = Conflict* → **📧 Draft clarification email** →
   **🚀 Open Directly in Outlook**.
4. **Stories & Tests (1 min):** approve a requirement → **🔁 Regenerate stories & tests** → Gherkin **✏️ Quick Edit**
   → **🧩 Jira push** in simulation (EXP-101 …).
5. **Export (30 s):** coverage gaps → Final Word BRD and Jira CSV.
